外部送信に関する公表事項

「美運優惠」の iPhone アプリとウェブ版 amex.0x6.ai は、ご利用中に、あなたの端末から次の送信先へ情報を送ります。電気通信事業法第27条の12にもとづき、送信される情報の内容、送信先、利用目的をお知らせします。

最終更新：2026年11月28日

タリーバッドのリワード広告については タリーバッドの外部送信に関する公表事項 をご覧ください。

送信先は3つGoogle LLC、Cloudflare, Inc.、運営者のサーバー（amex.0x6.ai）です。
アプリは現在地を送りませんiPhone アプリでは、位置情報を端末の中だけで使います。
iPhone の広告は許可制ウェブ版に広告はありません。iPhone 版は、トラッキングを許可した場合にのみ非パーソナライズ広告を読み込みます。

Google LLC（広告配信と同意の管理）

美運優惠 1.3 の iPhone アプリは、Google Mobile Ads SDK と User Messaging Platform を利用します。IP アドレスとそこから推定されるおおまかな地域、端末識別子、広告データ、アプリの操作状況、診断データが Google LLC（米国）に送信される場合があります。Google は広告配信と効果測定、無効なトラフィックの防止、プライバシー設定の管理に利用します。広告には選択したカード、検索語句、正確な位置情報を送信しません。必要に応じて、設定の「このアプリについて」から広告のプライバシー設定を変更できます。「周辺」または「オンライン・台湾全域」を初めて開くと、iOS が App Tracking Transparency（ATT）の許可を求める場合があります。許可した場合にのみ、アプリは Google の広告・同意管理 SDK を有効にします。AdMob は非パーソナライズ広告をリクエストし、配信や効果測定に iOS の広告識別子（IDFA）などの端末識別子を使用する場合があります。許可しない場合、広告の読み込みや表示は行いません。iOS の「設定 → プライバシーとセキュリティ → トラッキング」で選択を変更できます。許可を取り消すと、広告を非表示にして新しい広告リクエストを停止します。優待機能は引き続きすべて利用できます。Google Mobile Ads SDK のプライバシーマニフェストでは、端末識別子がトラッキングに使用されるデータとして記載されています。Google は広告配信や効果測定、無効なトラフィックの防止のため、クライアント情報や一部を切り詰めた IP アドレスなどを入札に参加する広告パートナーに提供する場合があります。このアプリが利用する Google の設定では、第三者による広告配信と効果測定が許可されます。データ収集が許可されている入札パートナーは、適用されるプライバシー設定とポリシーに従い、対象となる入札リクエストのデータを使ってオーディエンスリストやユーザープロファイルを作成する場合があります。詳しくは Google プライバシーポリシーと Google の入札データ収集に関する説明をご確認ください。

Cloudflare, Inc.（通信の中継と不正利用の防止）

送信先
Cloudflare, Inc.（米国）
送信の仕組み
iPhone アプリとウェブ版から amex.0x6.ai への通信は、すべて Cloudflare を経由します。
ウェブ版では、さらに Cloudflare Turnstile（人によるアクセスか、自動プログラム（ボット）によるアクセスかの確認）を使います。
送信される情報
  • IP アドレス、アクセス日時、アクセス先の URL、ブラウザやアプリの種類を示す情報（User-Agent）など、通信に関する情報
  • ウェブ版のみ：Turnstile の確認に使う、ブラウザと端末の特徴（暗号化通信の設定に関する情報など）
  • ウェブ版のみ：セキュリティのための Cookie（設定されている場合）
利用目的
  • 当方：サーバーへの通信を中継・保護し、ボットによる大量アクセスや攻撃を防ぐため
  • Cloudflare：これらのサービスの提供と、ボット判定の精度の改善のため
詳しい情報
Cloudflare プライバシーポリシー（英語）
Turnstile プライバシー補足（英語）
04

運営者のサーバー（amex.0x6.ai）

送信先
0x6.ai（このサービスの運営者）
送信の仕組み
iPhone アプリとウェブ版が、優待データの取得と検索のために送ります。
送信される情報
  • iPhone アプリ：起動したとき、アプリに戻ったとき、手動で更新を確認したときの、データ更新の確認。送るのは、アプリの署名（このアプリからのリクエストであることを確かめるための値）、時刻、手元のデータのバージョンです。更新があれば、優待とラウンジのデータをダウンロードします。現在地、端末の識別子、個人を特定できる情報は含みません。
  • ウェブ版：近くの優待を探すときの検索の中心の座標（現在地の利用を許可した場合は現在地、それ以外は地図の中心）、検索範囲、選んだカードとカテゴリ、詳細を開いた優待の ID
  • ウェブ版：Turnstile の確認結果と、確認後に発行される、短時間だけ有効なトークン。確認のため、サーバーからこの結果と IP アドレスを Cloudflare に送ります。
利用目的
  • 優待とラウンジのデータを届けるため
  • 近くの優待を検索して表示するため
  • ボットによる大量アクセスや不正な利用を防ぐため

サーバーは、座標をデータベースにもログにも保存しません。アプリのデータ更新の確認では、送信元を記録しません。ウェブ版のページ閲覧は、1日ごとの合計数だけを集計しています。

送信を止めたいとき

Google と Cloudflare への送信は、地図の表示と通信の保護に欠かせないため、アプリやウェブ版の中で個別に止める設定はありません。送信を望まない場合は、アプリやウェブ版のご利用をお控えください。位置情報の許可は、端末やブラウザの設定からいつでも取り消せます。

タリーバッド · 任意のリワード広告

最終更新 2026年11月28日

送信先
Google LLCおよびその関係会社。リワード広告にはGoogle Mobile Ads SDKを、広告のプライバシー設定と同意の管理にはUMPを使います。
送信される情報
IPアドレスとそれから推定されるおおまかな地域、端末やアプリの識別子、アプリやOSに関する情報、広告や表示回数に関するデータ、タップや動画視聴などの操作、プライバシー設定や同意の状態、パフォーマンスやクラッシュなどの診断情報。 Google Mobile Ads SDKのプライバシー宣言に基づき、App Storeのプライバシーラベルでは、端末識別子をトラッキングに使用される可能性のあるデータとして開示しています。
利用目的
当方は、任意の広告視聴によるレビューの解放と、適用されるプライバシー設定の確認に利用します。Googleは広告の配信、表示頻度の制御、広告効果の集計、不正なトラフィックの防止、サービスの維持・改善、広告のプライバシー設定の適用に利用します。

広告による解放を選ばなければ、この広告の手順を利用する必要はありません。対象地域では詳細レビューの「広告のプライバシー設定」を利用できます。Apple／Googleのサインインや、任意の同期・バックアップに伴う送信は、このページの各項目をご覧ください。
